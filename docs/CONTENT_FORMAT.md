# Формат контента

Контент — это файлы, а не код. Приложение читает их из бандла (позже — из скачанного
дополнительного контента), поэтому новый эпизод добавляется без правки Swift.
Проверка: `python3 tools/validate.py content/seasons/<сезон>`.

## Раскладка

```
content/seasons/s1-noir/
  season.json            библия сезона в машинном виде: персонажи, голоса, улики, концовки
  bible.md               библия сезона для людей: мир, тон, герои, арка сезона
  episodes/e01/
    outline.md           синопсис и поэпизодный план сцен (согласуется с владельцем)
    review.md            замечания ревьюера и их статус
    episode.json         готовый эпизод: сцены, реплики A2/B1 на en и es, выборы, словарь
    art/s01.svg          иллюстрации сцен
    art/prompts.md       промпты к иллюстрациям (для перегенерации внешним генератором)
```

## Языки и уровни

- Изучаемые языки: `en`, `es`. Уровни: `A2`, `B1` — две версии одного текста с одинаковыми
  сценами, репликами и выборами (одинаковые `id`), отличается только формулировка.
- Языки интерфейса и переводов: `ru`, `en`, `es`.
- Любой учебный текст — объект `Text`:
  `{"en": {"A2": "...", "B1": "..."}, "es": {"A2": "...", "B1": "..."}}`.
- Любой текст интерфейса (названия, описания улик) — объект `UIText`: `{"ru": "...", "en": "...", "es": "..."}`.

## season.json

```json
{
  "id": "s1-noir",
  "title": {"ru": "...", "en": "...", "es": "..."},
  "summary": {"ru": "...", "en": "...", "es": "..."},
  "episodes": ["e01", "e02", "e03", "e04", "e05"],
  "free_episodes": ["e01"],
  "characters": [
    {
      "id": "marta",
      "name": {"en": "Martha Reyes", "es": "Marta Reyes"},
      "role": {"ru": "...", "en": "...", "es": "..."},
      "portrait": "art/marta.svg",
      "voice": {"gender": "female", "pitch": 1.1, "rate": 0.95,
                "locale": {"en": "en-GB", "es": "es-MX"}},
      "relationship": true
    }
  ],
  "clues": [{"id": "torn_ticket", "title": UIText, "text": UIText, "art": "art/clue_ticket.svg"}],
  "endings": [
    {"id": "truth", "title": UIText, "summary": UIText},
    {"id": "shadow", "title": UIText, "summary": UIText}
  ]
}
```

- `narrator` — зарезервированный говорящий, его голос — системный голос языка.
- `voice` — параметры системного голоса Apple (`AVSpeechSynthesisVoice` по `locale` и полу,
  `pitchMultiplier`, множитель скорости). Своих аудиофайлов нет: реплику и нажатое слово
  произносит голос персонажа.
- `relationship: true` — у персонажа есть шкала отношений (целое число, старт 0).

## episode.json

```json
{
  "id": "e01",
  "season": "s1-noir",
  "number": 1,
  "title": UIText,
  "minutes": 12,
  "start": "s01",
  "scenes": [
    {
      "id": "s01",
      "art": "art/s01.svg",
      "place": UIText,
      "on_enter": {"clue": "torn_ticket"},
      "lines": [
        {"id": "l1", "speaker": "narrator", "text": Text},
        {"id": "l2", "speaker": "marta", "mood": "worried", "text": Text}
      ],
      "choices": [
        {"id": "c1", "text": Text, "effects": {"rel": {"marta": 1}, "set": ["trusted_marta"]}, "goto": "s02"},
        {"id": "c2", "text": Text, "effects": {"rel": {"marta": -1}}, "goto": "s03"}
      ]
    },
    {
      "id": "s07",
      "lines": [...],
      "next": [
        {"if": {"flags": ["trusted_marta"], "rel": {"marta": 2}}, "goto": "s08"},
        {"goto": "s09"}
      ]
    },
    {"id": "s12", "lines": [...], "next": "END"}
  ],
  "vocabulary": {
    "en": {"A2": [Word], "B1": [Word]},
    "es": {"A2": [Word], "B1": [Word]}
  }
}
```

### Сцена

- Либо `choices` (2–3 штуки), либо `next`. `next` — `id` сцены, `"END"` (конец эпизода),
  `"ENDING:<id>"` (концовка сезона, только в последнем эпизоде) или список условных
  переходов; последний элемент списка без `if` — переход по умолчанию.
- `on_enter.clue` — улика, которую игрок получает, войдя в сцену. Улика может выдаваться и
  выбором: `effects.clue`.
- `art` — путь относительно папки эпизода. Сцена без `art` показывает иллюстрацию предыдущей.

### Эффекты и условия

- `effects.rel` — изменение отношений: `{"marta": 1, "leo": -1}`.
- `effects.set` / `effects.unset` — флаги сезона (живут между эпизодами).
- `effects.clue` — улика.
- Условие `if`: `flags` — все должны быть установлены (`"!flag"` — не установлен),
  `rel` — отношения не ниже числа, `clues` — все улики собраны. Все части через «И».
- Условие можно повесить и на выбор: `requires` — выбор показан, только если условие верно.

### Слово словаря (`Word`)

```json
{"word": "witness", "lemma": "witness", "pos": "noun",
 "tr": {"ru": "свидетель", "en": "witness", "es": "testigo"},
 "scene": "s03", "line": "l2"}
```

- Словарь эпизода — «новые слова» этого уровня: из них строятся итог «вы встретили N новых
  слов» и тренировка в конце эпизода. 10–20 слов на уровень.
- `word` должно встречаться в тексте указанной реплики (без учёта регистра). Перевод нажатого
  слова, которого нет в словаре, делает переводчик Apple на устройстве.
- `tr` — переводы в контексте этой сцены на все языки интерфейса; перевод на язык, совпадающий
  с изучаемым, — короткое толкование простыми словами.

## Правила, которые проверяет валидатор

- Все `Text` заполнены для `en`/`es` × `A2`/`B1`, все `UIText` — для `ru`/`en`/`es`.
- `id` сцен, реплик и выборов уникальны; переходы ведут в существующие сцены.
- Все сцены достижимы из `start`; из любой сцены можно дойти до `END`/`ENDING`.
- У сцены 2–3 выбора или `next`; говорящие и улики объявлены в `season.json`.
- Слова словаря встречаются в своих репликах; каждый уровень — 10–20 слов.
- Файлы иллюстраций существуют.
