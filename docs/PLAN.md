# План MVP

ТЗ: один сезон-детектив из 5 эпизодов по 10–15 минут; en и es, уровни A2 и B1; интерфейс
ru/en/es; нажатие на слово — перевод, озвучка, карточки; серия дней, карта эпизодов,
коллекция улик; первый эпизод бесплатно, сезон $4.99, подписка $4.99/мес или $29.99/год с
пробной неделей. Не входит: аккаунты, сервер, мультиплеер, iPad, Android.

Готово, когда: 5 эпизодов проходятся на обоих уровнях и языках; покупки работают в
песочнице; слова попадают в карточки; есть ролики и скриншоты для стора.

## Шаг 1. Формат эпизода и конвейер агентов
- [x] Формат контента и валидатор (`docs/CONTENT_FORMAT.md`, `tools/validate.py`).
- [x] Навыки: `new-episode`, `story-writer`, `story-reviewer`, `illustrator`, `story-integrator`.
- [ ] Библия сезона и план эпизода 1 → согласование с владельцем.
- [ ] Эпизод 1 целиком через конвейер (текст, иллюстрации, словарь).

## Шаг 2. Каркас приложения
- Подключить LeoCore, перевод и озвучку из Leo.
- Плеер эпизода из JSON: кадр, реплики с голосами героев, выборы, состояние (флаги,
  отношения, улики), сохранение прогресса.
- Нажатие на слово: перевод (словарь эпизода, иначе переводчик Apple), озвучка, «в карточки».
- Выбор изучаемого языка и уровня при старте и в настройках.

## Шаг 3. Весь сезон и прогресс
- Эпизоды 2–5 через конвейер, две концовки.
- Итог эпизода «вы встретили N новых слов» и короткая тренировка.
- Серия дней, карта эпизодов, коллекция улик, тренировка карточек (SM-2 из LeoCore).

## Шаг 4. Монетизация и стор
- StoreKit 2: сезон (разовая покупка), подписка с пробной неделей; проверка в песочнице.
- Скриншоты и ролики для стора, тексты, политика.
